# A Childhood Memory

One sentence, at most 280 characters, that brings back a childhood
memory: a cold kitchen floor at dawn, a kettle waiting to boil, and a
mother humming a song she never finished. A single concrete image,
left unanswered, so the ache lingers after the sentence ends.

## How to run it

Requires Python 3.13 (standard library only, no network at run time):

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (UTF-8, exactly one
line, 1–280 characters), checked by gate assertions inside `main.py`.
